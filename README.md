## 📁 Repository Structure

```text
├── Abstract-Data-Type/       # Concepts on ADTs
├── Encapsulation/            # Data abstraction & modular code design
├── Lab_Questions/            # Practical classroom assignments
├── Sorting and Searching/    # Sorting and searching algorithms
├── Variadic function/        # Variable arguments logic in C
├── Circular_list.c           # Circular Linked List operations
├── Circular_queue.c          # Circular Queue implementation
├── Double_ended_queue.c      # Deque implementation
├── Double_linked_list.c      # Doubly Linked List implementation
├── Polynomial.c              # Polynomial representation & manipulation
├── Round_robin_queue.c       # Round-Robin scheduling logic
├── Tree.c                    # Tree operations and traversals
└── call_by_value_and_reference.c # Memory passing concepts
```

## 💡 Key Topics Covered
Linked Lists: Doubly Linked Lists, Circular Linked Lists

Queues: Circular Queue, Double-Ended Queue (Deque), Round-Robin Queue

Trees: Binary Trees & BST concepts

Core Concepts: Abstract Data Types (ADT), Encapsulation, Function Arguments (Call by Value vs Reference), Variadic Functions

Algorithms: Sorting, Searching, and Algebraic Operations

## 🛠️ Getting Started
Prerequisites
Ensure you have a C compiler installed on your machine:

GCC (GNU Compiler Collection) or Clang

## ⚙️ How to Run
Clone the repository:
```
git clone [https://github.com/apoorv-git-code/Data-Structure-and-Algorithms.git](https://github.com/apoorv-git-code/Data-Structure-and-Algorithms.git)
cd Data-Structure-and-Algorithms
```
```
Compile any program (e.g., Tree.c):

gcc Tree.c -o tree
```
```
Run the compiled executable:

./tree
```
